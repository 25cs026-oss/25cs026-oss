### 🧠 Core Engineering Philosophy

I believe that clean, maintainable, and optimized code is the hallmark of a professional developer. My coding process adheres to these engineering standards:

*   **DRY (Don't Repeat Yourself)**: Minimizing code duplication by abstracting reusable functions, templates, and classes.
*   **KISS (Keep It Simple, Stupid)**: Designing systems that are easy to read and understand, avoiding unnecessary over-engineering.
*   **Memory & Resource Optimization**: Leveraging C++ pointers, references, and SQL indexes to design low-latency applications.
*   **Robust Testing**: Writing modular functions that are easy to debug and unit-test.
